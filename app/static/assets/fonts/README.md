# Fontes da Impulso

- Inter: leitura e controles, pesos variáveis 400–800.
- Manrope: títulos, pesos variáveis 400–800.
- Arquivos WOFF2 do subconjunto latino baixados de Google Fonts; servidos localmente pelo projeto, sem requisições externas durante o uso do site.
- Ambas sob SIL Open Font License 1.1; licenças preservadas em `Inter-OFL.txt` e `Manrope-OFL.txt`.
- Origem: `fonts.googleapis.com/css2?family=Inter:wght@400..800&display=swap` e equivalente para Manrope. Licenças do repositório `google/fonts`, diretórios `ofl/inter` e `ofl/manrope`.
